Политика конфиденциальности (Privacy Policy)

Последнее обновление: 2024 год

1. Какую информацию мы собираем

Наше приложение (AI Numerologist Bot) взаимодействует с Instagram Graph API. При использовании бота мы получаем доступ к следующей информации, предоставляемой платформой Meta: ID пользователя Instagram (Instagram User ID), имя пользователя (Username) и текст отправленных боту сообщений (содержащих, например, дату рождения).

2. Как мы используем информацию

Мы используем собранные данные (в частности, дату рождения) исключительно для: генерации персонального ответа (нумерологического расчета) с помощью нейросетей (Google Gemini); обеспечения обратной связи через сообщения в Instagram Direct.

3. Защита и передача данных

Мы не продаем, не передаем и не раскрываем ваши персональные данные третьим лицам. Исключение составляет техническая передача текста сообщений в API Google (Gemini) для генерации текстового ответа, после чего ответ возвращается обратно. Google API обязуется не использовать эти данные для обучения публичных моделей.

4. Запрос на удаление данных

Если вы хотите, чтобы мы удалили всю историю вашей переписки с ботом и ваш Instagram ID из нашей технической базы, напишите нам в личные сообщения аккаунта: @ai_numerologist.
